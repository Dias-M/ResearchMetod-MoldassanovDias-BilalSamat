# Task 3 runbook: from raw corpora to the report

All commands run from the repository root. Every step is resumable. Nothing here is generated by hand: the report is built from the files the steps produce.

## 0. Environment
```bash
python -m venv .venv
.venv\Scripts\activate            # Windows;  Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt   # exact pins, Python 3.11
```
If Python 3.11 is not available, install the same packages without pins (`pip install numpy pandas scikit-learn scipy statsmodels pyyaml tqdm tabulate matplotlib seaborn reportlab`; add `torch transformers datasets accelerate` for DistilBERT and the LLM). For the heavy steps 3–4 a free Google Colab GPU is much faster than a laptop CPU.

## 1. Data (needs internet)
```bash
python scripts/01_download_data.py            # Enron ham, SpamAssassin ham
```
Phishing corpora are manual (see `data/README.md`): put the Nazario `.mbox` files and one modern phishing CSV (`text,label,source`) into `data/raw/`. Check licences and URLs first.

Then build the two corpora used in the reported run (English only, near-duplicates collapsed, leakage markers neutralised; reads the two public GitHub repositories listed in `docs/run_notes.md`):
```bash
python scripts/00_build_corpus.py --phish-dir <phishing_pot>/email --ceas <phishing-email-dataset>/CEAS_08.csv
```

## 2. Clean and split
```bash
python scripts/02_prepare_data.py             # dedupe, conflicting labels, 70/15/15 split -> data/processed/emails.csv
```

## 3. LLM paraphrase of phishing only
```bash
python scripts/03_paraphrase.py --backend hf --splits train val test
```
CPU: about 10–30 s per e-mail with Qwen2.5-1.5B. If time is short, add `--limit 600` (the run is resumable; rerun to continue). Only e-mails that pass the quality filter form matched pairs.

## 4. Train and evaluate: 5 seeds, plain and augmented
```bash
python scripts/04_train_eval.py --models tfidf_lr distilbert --seeds 42 43 44 45 46
python scripts/04_train_eval.py --models tfidf_lr distilbert --seeds 42 43 44 45 46 --augment
```
Minimum acceptable: `tfidf_lr` alone. The zero-shot LLM is optional (`--models tfidf_lr distilbert zeroshot_llm --max-test 300`).

## 5. Statistics
```bash
python scripts/05_stats.py                    # McNemar + Holm, RQ3 criterion -> results/summary.csv, summary.md
```

## 6. Processing, model check, figures
```bash
python src/process_data.py                    # outlier flag (kept), summary over seeds, bootstrap CI, model check
python src/visualize.py                       # reports/figures/fig1..fig3 (.pdf + 300 DPI .png)
```

## 7. Notebook and report
```bash
cd notebooks && jupyter nbconvert --to notebook --execute --inplace 01_task3_analysis.ipynb && cd ..
python src/make_report.py --group "YOUR-GROUP" --repo "https://github.com/<user>/<repo>"
```
`make_report.py` stops if there are fewer than 2 seeds or fewer than 30 matched pairs, so it cannot be built from the 10-row sample.

## 8. What to commit
`data/processed/metrics_summary.csv`, `paired_delta.csv`, `model_check.csv`, `reports/figures/*`, `reports/TASK3_report.pdf`, the executed notebook. Raw corpora and `results/` stay out of git (`.gitignore`). Send `results/*.csv` to the co-author if the report must be rebuilt elsewhere.
