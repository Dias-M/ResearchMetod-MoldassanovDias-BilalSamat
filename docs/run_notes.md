# Notes on the reported run

**Data.** Phishing: Phishing Pot (github.com/rf-peixoto/phishing_pot, CC BY-NC 4.0, commit 80a4867 of 2026-10-28), 12,865 real phishing e-mails collected by honeypots. Legitimate e-mail: CEAS-08, rows with label 0 (github.com/PHP4Life/phishing-email-dataset, file CEAS_08.csv; the same file holds spam, which was not used). Built by scripts/00_build_corpus.py: English only (the corpus is multilingual), near-duplicate campaigns collapsed, then the standard cleaning of scripts/02_prepare_data.py. Result: 1,639 phishing and 14,865 legitimate e-mails; train 11,552, validation 2,475, test 2,477 (246 phishing, 2,231 legitimate).

**Leakage removed.** Two label giveaways were found and neutralised in both classes before splitting: the anonymiser string "phishing@pot" of the corpus and four-digit years (phishing 2019-2026 against legitimate 2007-2008). The result of the experiment did not change after this step.

**Deviation from the plan: the paraphraser.** The planned paraphraser (Qwen2.5-1.5B-Instruct) could not run in the environment of this run (no access to the model hub, no deep-learning libraries). Instead 97 phishing e-mails of the test split were paraphrased by Claude, a large language model, with the same instruction (keep the meaning, the links and the addresses; change the wording and the sentence structure). The e-mails were a random sample (seed 0) of the 111 test phishing e-mails of 160 to 900 characters; three explicit adult e-mails were skipped. All 97 paraphrases passed the quality filter (length ratio 0.5 to 1.5, all links kept). The conclusions therefore concern short e-mails and one LLM paraphraser; the paraphrases are in data/processed/paraphrases.csv.

**Deviation from the plan: detectors and research questions.** Only the TF-IDF + logistic regression detector was run; DistilBERT and the zero-shot LLM need a deep-learning stack that was not available. RQ3 (training with paraphrase augmentation) was not run because it needs paraphrases of the training set. RQ2 (logistic regression with e-mail length) was not run.

**Seeds.** TF-IDF + logistic regression is deterministic, so the five seeds give identical numbers and a confidence interval over seeds has zero width. Uncertainty is therefore shown by the paired exact test, the Clopper-Pearson bound on the share of lost e-mails, and the confidence interval of the score shift.

**Main limitation.** Legitimate e-mail (2008 mailing lists and personal mail) and phishing (modern marketing and crypto-wallet HTML e-mail) still differ in style after the cleaning, so the detector separates the two classes easily (recall about 98%) and has a large safety margin. A small effect of paraphrasing can be hidden by this ceiling; the result does not show that paraphrasing is harmless for detectors trained on harder, same-source data. The Phishing Pot honeypot also contains advertising and scam e-mails (casino, pills, lottery), not only credential phishing.
